# Патч-отчёт: точки в оракуле — атрибуция и NMS

Коммит: фиксы `post`/`oracle` для точечной разметки. Ветка `test/geo-pr55`.

## Симптом

Oracle-sweep 2026-11-11 (night3, 12 val-участков): f1 0.785, **456 из 461 FN
с причиной «вне сетки»**, при том что bbox-аудит (`grid_coverage_check`)
показывал Тимерево/Герите/Фалхан полностью покрытыми сеткой.

## Причины — две, обе в моём коде оракула

1. **Атрибуция.** Маска GT строилась как `y_seg[0] > 0`: канал 0 для всех
   классов и сег-ветка для точек. Точки попадают только в heatmap
   (`finds_points: 0 px / N hm`), классы с индексом > 0 — в свой канал.
   Итог: у точек и «старших» классов маска пустая → причина «вне сетки»
   врала, настоящий виновник скрывался.
2. **Реальная потеря точек в NMS.** Один общий NMS (радиус под полигоны,
   4-6 px) плюс общее окно пиков 7 px глотали плотные кластеры: точки через
   2-4 м давились ещё до матчинга. Синтетика: recall 0.636 на шаге 2-4 м,
   1.000 с шага 5 м. Тимерево (312 FN), Герите (36), Фалхан (17) — это оно.

## Что изменено

| Файл | Изменение |
|---|---|
| `src/expds/post/vectorize.py` | `PostConfig`: новые ключи `point_nms_radius_px` и `point_peak_window_px` (None — наследовать старые, обратная совместимость); `heatmap_to_points` использует point-окно; `postprocess`: раздельный NMS веток + проход-склейка BOTH с минимальным радиусом |
| `src/expds/eval/oracle.py` | маска GT: свой канал сегмента для полигонов, heatmap-канал класса для точек; детекции — «щедрый потолок» (обе ветки для всех классов); раздельный NMS + склейка — зеркально `postprocess` |
| `scripts/oracle_diag.py` | печать состава разметки (Poly/Point по классам) перед отчётом |
| `configs/night3.yaml` | `point_nms_radius_px: 1.5`, `point_peak_window_px: 3` |
| `tests/test_point_clusters.py` | новый: кластеры шага 2-5 м с point-параметрами восстанавливаются в f1 1.0; без них — честная атрибуция (не «вне сетки») |

## Проверено

    tests/test_point_clusters.py` — **67 passed**.
- `ruff check` — чисто.

  старым с точностью до порядка greedy-NMS (тесты не заметили).
